# Architecture

Next.js browser workspace → authenticated FastAPI API → SQLAlchemy metadata store. Background Python threads execute experiments. The simulation constructs each hospital's local features inside client training, clones the global model, optimizes locally, and returns only tensors and sample counts to the aggregation function. The sample-weighted state dictionaries update the global fusion model. A separate, fixed synthetic partition (seed 9182, 180 records) supplies all reported accuracy, precision, recall, F1, ROC-AUC, loss and confusion matrices.

Image features: grayscale normalization and 4×4 pooling, 16 dimensions. Text features: 16 explicit keyword frequencies. Fusion model: separate linear 16→8 projections with tanh, concatenated into 16 features, followed by a two-class prediction head. These are lightweight research baselines, without pretrained medical inference.

Client partitions use independent seeds and class imbalance to illustrate non-IID data. Local SGD supports a proximal penalty for FedProx. Each round records client losses, update byte counts, elapsed train-and-aggregate time and held-out metrics. The aggregation_seconds field measures the whole local-training/aggregation/evaluation round, not network latency. No real network traffic or secure aggregation is simulated.

Persistence: users and hospitals have dedicated tables. Owner-scoped research_records store typed JSON experiment metadata, rounds, evaluations, audits, reports and dataset catalog entries. This intentionally compact baseline does not implement the fully normalized enterprise schema in the original brief. Hospital sample counts describe synthetic training partition sizes; clinical counts are catalog metadata. Central text records contain token counts/model metadata, never raw text. Image records contain normalized 16-value embeddings and dimensions, never the uploaded file or DICOM patient metadata; embeddings themselves may leak information and are not safe for sensitive data.

Training tasks are process-local threads; pause/stop take effect between rounds, not midway through a batch. A process restart interrupts jobs. Experiments cannot be restarted; create a new one. Model weights are not retained after completion; stored evaluation reflects the actual model at completion. Server sessions require a stable JWT_SECRET across restarts. Frontend JWT is held in sessionStorage, with XSS exposure considerations. Researcher data visibility is owner-scoped, while hospitals are shared synthetic infrastructure and administrator-managed.
